# encar-filter

엔카닷컴 중고차 검색 결과에서 조건에 맞는 차량만 필터링하여 HTML 파일로 출력하는 CLI 도구입니다.

## 동작 방식

1. 입력한 엔카 검색 결과 페이지 URL의 `#!` 뒤 JSON에서 검색 조건(`action`)과 정렬 기준(`sort`)을 추출합니다.
2. 추출한 조건으로 엔카 검색 API를 50건씩 페이징하며 전체 매물 목록을 수집합니다.
3. 매물마다 차량 정보 API와 보험 이력 API를 조회해 필터 조건에 맞는 차량만 남깁니다.
4. 결과를 `result/YYYY-MM-DD_HH_MM_SS_<파일명>.html` 파일에 정렬 가능한 테이블로 저장합니다. (`result/` 디렉터리는 없으면 자동 생성)

## 필터 조건

- 렌트카/영업용/관용 이력이 있는 차량 제외 (보험 이력의 `loan`, `business`, `government`)
- 명의 변경 횟수 2회 이하
- 차량 정보 또는 차량번호를 조회할 수 없는 매물 제외

## 출력

`result/` 디렉터리에 단일 HTML 파일로 저장됩니다. CSS/JS가 모두 파일 안에 들어 있어 브라우저로 열기만 하면 되고, 별도 서버나 외부 라이브러리가 필요 없습니다.

- 기본 정렬은 가격 오름차순입니다.
- **사진**은 차량 정보 API의 실제 대표사진 경로로 표시하며, 클릭하면 엔카 상세 페이지를 새 탭으로 엽니다. 화면에 가까운 사진부터 불러오고, 사진이 없거나 로딩에 실패하면 `사진 없음`으로 표시합니다. 사진 로딩에는 인터넷 연결이 필요합니다.
- **연식은 보험이력 화면의 `2020년식`과 같은 값**을 사용합니다. 등록 연월과 구분하며, 조회한 보험이력에 연식이 없으면 `미확인`으로 표시합니다. 연식 정렬 시 미확인 값은 오름차순/내림차순 모두 뒤에 놓입니다.
- **연평균 마일리지**는 파일 생성일과 해당 연식의 1월 1일~12월 31일 사이 경과 일수로 계산한 추정 범위입니다. `주행거리 × 365.25 ÷ 경과 일수`로 최솟값·최댓값을 구하며, 파일을 나중에 다시 열어도 기준일은 바뀌지 않습니다.
- 범위 아래에 **중앙값 `(최솟값 + 최댓값) ÷ 2`**을 표시합니다. 1km/년 단위로 반올림한 중앙값으로 정렬하고, 표 위 **최소·최대 필터**로 차량을 좁힐 수 있습니다. 입력한 경계값을 포함하며, 한쪽만 입력하면 그쪽 제한만 적용합니다. 필터 초기화는 정렬 조건을 유지합니다.
- 연식이 없으면 연평균 마일리지는 `미확인`, 파일 생성일이 해당 연식의 12월 31일 이전·당일이면 `계산 불가`입니다. 두 경우 모두 중앙값 정렬에서 뒤에 놓이며, 최소·최대 필터를 적용하면 제외됩니다.
- **열 제목을 클릭할 때마다 오름차순 → 내림차순 → 적용 안 함**으로 순환합니다. 다른 열을 클릭해도 기존 조건은 유지되어 여러 항목을 동시에 적용할 수 있습니다. Shift/⌘를 누를 필요가 없습니다.
- **먼저 선택한 조건이 우선**이며, 해당 값이 같을 때 다음 조건으로 정렬합니다. (예: 명의 변경 오름차순 → 가격 내림차순) 방향만 바꾸면 우선순위는 유지되고, 해제 후 다시 선택하면 마지막 순위에 추가됩니다.
- 헤더와 표 위 조건에 ①②③ 우선순위가 표시됩니다. 조건 옆 **← → 버튼**으로 우선순위를 바꿀 수 있습니다.
- **전체 해제**하거나 모든 조건을 개별 해제하면 기본 순서(가격 오름차순)로 돌아갑니다. 처음에는 선택된 조건이 없으며, 모든 조건 값이 같으면 원래 순서를 유지합니다.
- 열 제목에 키보드로 이동한 뒤 Enter/Space를 눌러도 정렬을 바꿀 수 있습니다.
- 정렬은 표시 문자열(`1,290만원`)이 아니라 각 셀의 `data-value`(숫자)를 기준으로 하므로 `990만원 < 1,290만원`처럼 올바르게 비교됩니다.
- 헤더 고정(sticky), 다크 모드, 가로 스크롤, 모바일 반응형 레이아웃을 지원합니다.
- 숫자는 고정폭(`tabular-nums`)으로 표시해 가격·마일리지의 자릿수가 세로로 맞춰집니다.
- 짝수 행 배경, 행 hover, **정렬 중인 열 배경 강조**로 긴 표에서도 행과 기준 열을 놓치지 않습니다.
- 사고 횟수와 평균 피해액이 `0`인 셀은 옅게 표시되어 무사고 매물이 한눈에 구분됩니다.

| 항목 | 설명 | 정렬 |
|------|------|------|
| 번호 | 가격 오름차순 기준 일련번호 | O |
| 사진 | 차량 대표사진 (클릭 시 상세페이지) | X |
| 연식 | 보험 이력의 연식 (예: 2020년식), 없으면 미확인 | O |
| 명의 변경 | 명의 변경 횟수 | O |
| 가격 | 만원 단위 | O |
| 사고 횟수 | 내 차 피해 사고 횟수 | O |
| 평균 피해액 | 사고당 평균 피해액 (만원) | O |
| 마일리지 | 주행거리 (km) | O |
| 연평균 마일리지 | 생성일 기준 추정 범위와 중앙값 (km/년) | O (중앙값) |
| 링크 | 엔카 상세페이지 (새 탭) | X |

## 사용법

### 설치

```bash
uv sync
```

### 실행

```bash
uv run encar.py
```

실행하면 두 가지를 입력받습니다.

1. `차량 검색 조건 입력 (파일명):` — 출력 파일 이름에 사용됩니다. (예: `그랜저`)
2. `엔카 검색 결과 페이지 URL 입력:` — 아래 방법으로 복사한 URL을 붙여넣습니다.

### 검색 결과 페이지 URL 얻는 방법

1. [엔카닷컴](https://www.encar.com)에서 원하는 조건(제조사, 모델, 연식, 가격, 정렬 등)으로 검색합니다.
2. 검색 결과 페이지의 **브라우저 주소창 URL을 그대로 복사**합니다.

주소창 URL은 다음과 같이 `#!` 뒤에 검색 조건 JSON이 붙어 있어야 합니다.

```
http://www.encar.com/dc/dc_carsearchlist.do?carType=kor#!%7B%22action%22%3A%22(And.Hidden.N._.(C.CarType.A._.Manufacturer.현대))%22%2C%22toggle%22%3A%7B%7D%2C%22layer%22%3A%22%22%2C%22sort%22%3A%22ModifiedDate%22%7D
```

`#!`가 없는 URL을 입력하면 검색 조건을 찾을 수 없다는 메시지와 함께 종료됩니다.

## 프로젝트 구조

책임에 따라 모듈을 나눴습니다.

```
encar.py                      진입점 (CLI 실행)
encar_filter/
├── cli.py                    사용자 입출력과 실행 흐름
├── collector.py              검색 → 상세 조회 → 필터링 파이프라인
├── api.py                    엔카 API HTTP 호출
├── urls.py                   검색 페이지 URL 파싱, API/상세 URL 생성
├── filters.py                보험 이력 해석과 필터 조건 (CarFilter)
├── models.py                 CarListing, InspectedCar 데이터 구조
├── report.py                 HTML 리포트 렌더링
└── templates/report.html     리포트 템플릿 (CSS/JS 포함)
```

필터 기준은 `filters.CarFilter` 한곳에 모여 있습니다. 명의 변경 허용 횟수나 영업용 제외 여부를 바꾸려면 `cli.py`에서 `CarFilter(max_owner_change_cnt=3, exclude_commercial=False)`처럼 넘기면 됩니다.

표의 모양과 정렬 동작은 `templates/report.html`만 고치면 되고, 파이썬 코드는 건드릴 필요가 없습니다.

## 요구사항

- Python >= 3.9
- requests, tqdm
