# encar-filter

엔카닷컴 중고차 검색 결과에서 조건에 맞는 차량만 필터링하여 마크다운 파일로 출력하는 CLI 도구입니다.

## 필터 조건

- 렌트카/영업용/관용 차량 제외
- 명의 변경 횟수 2회 이하
- 사고 이력 정보 포함

## 출력 항목

가격순 정렬된 마크다운 테이블로 출력됩니다.

| 항목 | 설명 |
|------|------|
| 명의 변경 | 명의 변경 횟수 |
| 가격 | 만원 단위 |
| 사고 횟수 | 내 과실 사고 횟수 |
| 평균 피해액 | 사고당 평균 피해액 (만원) |
| 마일리지 | 주행거리 (km) |
| URL | 엔카 상세페이지 링크 |

## 사용법

### 설치

```bash
uv sync
```

### 실행

```bash
uv run encar.py
```

1. 파일명을 입력합니다 (출력 파일 이름에 사용).
2. 엔카 검색 결과 API URL을 붙여넣습니다.

### API URL 얻는 방법

1. [엔카닷컴](https://www.encar.com)에서 원하는 조건으로 검색합니다.
2. 브라우저 개발자 도구(F12) > Network 탭에서 `search` 요청의 URL을 복사합니다.

## 요구사항

- Python >= 3.9
- requests, tqdm
